pea · 新建组 UI 修复预览

去掉外层 ReactFlow 直角黑框，保留并增强 group 圆角边界
问题 1：组边界
修复前
新建组
ReactFlow 默认 .react-flow__node-group 自带 1px 深色直角边框 + 3px 小圆角，与内部 .pea-group-node 的 18px 圆角叠加，出现「外层直角、内层圆角」的双层错位感。
修复后（默认状态）
新建组
外层 wrapper 去掉了深色直角边框；.pea-group-node 增加淡淡的背景填充（rgba(240,242,245,0.95)）和 1px 深色边框（rgba(0,0,0,0.24)），在浅色画布上能看清组范围。
修复后（选中状态）
新建组
选中时边框变为品牌蓝色（rgba(31,162,220,0.78)）并带内发光 + 外发光，组范围更加明显。
问题 2：切换背景颜色环
修复前
切换背景
原实现是实心圆点，用户难以直观看到当前选中的颜色。
修复后
切换背景
改为颜色环（ring）：中心透明，3px 色环显示当前颜色，透明度经过增强，肉眼可辨识。
改动文件
pea-server/web/src/styles/index.css：覆盖 ReactFlow group wrapper 默认样式；增强 .pea-group-node 背景/边框/选中态；新增 prefers-color-scheme: light 媒体查询兜底。
pea-server/web/src/components/GroupNode.tsx：bgColor 为 transparent 时不写内联 background，让 CSS 默认样式生效。
verify/_check_group_ui_fix.py：自动化验证脚本，截图检查 group 边界和切换背景颜色环。
