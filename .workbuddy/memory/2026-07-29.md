## Linux 部署审查 (start.sh / docker-compose)
- `start.sh` 本身是标准 bash，`.gitattributes` 已设 `eol=lf`，git 克隆到 Linux 自动转 LF，无 CRLF 坑。无需大改，仅修正两处过期打印 URL（8080→8088, 4000→4100）。
- `open_browser()` 在无桌面的 Linux 服务器上无 xdg-open 会静默失败（`|| true`），无害。
- **docker-compose 生产加固**：
  - 把 mysql/redis/minio 的发布端口绑定到 `127.0.0.1`（3306/6379/9000/9001），容器间仍走 docker 内网互通，不受影响；避免公网弱口令库被扫。
  - 密钥/口令改为 `${VAR:-默认}` 形式参数化（JWT_SECRET / DB 用户密码 / MinIO），向后兼容本地默认值，允许 `.env` 覆盖。
  - 新增 `pea-server/.env.example` 模板；`.env` 已被根 `.gitignore` 忽略。
- **部署提醒**：Linux 需把当前用户加入 `docker` 组或用 root 跑；生产应再放一层 nginx/caddy 做 HTTPS；已存在 mysql_data 卷以旧口令为准，迁移时口令不能变。
