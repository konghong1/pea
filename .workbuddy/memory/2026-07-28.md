## Agnes 视频参数排查 + 修复（2026-07-28 16:50）
- 用户反馈"视频生成不出来"，对照官方 agnes-video-v2.0 文档逐项核查，发现 4 处代码层问题：
  1. 图生视频单图参数形状错误：旧代码把 1 张参考图塞进 `extra_body.image=["url"]` 数组且无 mode；
     官方 img2vid 应为顶层 `image="url"`(字符串) + `mode:"ti2vid"`。≥2 图 keyframes 走
     `extra_body.image` 数组 + `extra_body.mode:"keyframes"`（此分支本就正确）。
  2. `duration` 前端传字符串 `"5s"`，后端 `int("5s")` 抛错被 `_clamp_int` 兜底成默认 5s → UI 选的时长被静默丢弃。
     已修：后端剥离 "s" 单位再转整秒。
  3. `num_frames = duration*frame_rate+1` 从未归一化，frame_rate 非 8 倍数（如 30）或 duration 过大时
     违反 Agnes 硬约束 `≤441 且 8n+1` → 400。已修：min(441) + 向下取整到最近 8n+1。
  4. 后端完全忽略前端 `gen_mode`/`audio_enabled`，生成模式选择无效。已修：读 `gen_mode`，缺省按参考图数量推断。
- 另：`video_poll_max_s` 300→900（Agnes 晚高峰 5-10min，原 300s 误杀长任务；非 env 覆盖项，config.py 默认值生效）。
- 已改文件：agnes_provider.py(_build_video_payload)、config.py(video_poll_max_s)。注意容器 /app 烘焙，须 rebuild 生效。
- 仍需用户侧确认：ai_models.model_name 必须严格 = "agnes-video-v2.0"、base_url = "https://apihub.agnes-ai.com"、api_key 有效（否则 401）。
- 经验：接入外部 API 时，参数防腐层必须 100% 对齐官方文档的"字段名 + 类型 + 单/复数值形态"，
  且对枚举类参数（mode）做显式映射而非隐式推断。
