### **关键崩溃修复（回答用户"为何卡在自测中"）**
- **根因**：`TapTV` 渲染 `JSON.parse(w.media_urls)`，而 `works.media_urls` 是 MySQL JSON 列，mysql2 读出已是**数组 `[]`** → `JSON.parse([])` 强转空串 → `Unexpected end of JSON input` → **TapTV 渲染抛错 → React 整树卸载**。这正是 E9 此前"卡在自测中"的真实原因——自测中真撞到崩溃，不是没测。
- **修复**：`hasMedia()` 兼容 数组/字符串/null 三态；canvas 两条 `JSON.parse(graph_json)`（挂载路径空串/`null` 隐患）也改防御式。
- antd v5 无图标主按钮文本插空格（`'发 布'`）→ Playwright 精确文本匹配失效，验证脚本改按 `.ant-modal-footer .ant-btn-primary` 类名定位。
