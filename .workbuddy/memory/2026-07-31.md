## 视频生成失败排查（根因=上游队列满，非代码 bug）

### 现象
- 用户反馈「视频生成不出来，一直报错」。前端 `PeaNode.tsx:1059` 的 `parseGenError` 把 HTTP 5xx 统一显示成「生成服务暂不可用 / 上游接口返回异常，已自动退款」。

### 根因（外部上游容量/限流，非我们 bug）
- 编排器 `generation-orchestrator` 日志：`[agnes] attempt 1 got HTTP 503` → `[dispatcher] submit failed ... video-submit HTTP 503: {"code":"video_queue_full","message":"video queue is full, please retry later"}`。
- DB `generation_jobs`(type=video)：12:40 还 `done` 1 个，12:47–13:10（≈20:47–21:10 GMT+8）连续 5 个 `refunded`（全 `video_queue_full`）。即晚高峰上游视频队列被打满后持续饱和。
- **直接探测证实**：用 DB 中 Agnes key（`ai_providers.id='agnes'`，base=`https://apihub.agnes-ai.com/v1`，视频模型 `agnes-video-v2.0`）从同出网路径打 `GET /v1/models` → **200**（6 模型含 `agnes-video-v2.0`，证明我们网络+密钥健康）；打 `POST /v1/videos`（最小合法 payload）→ **503** + body `{"code":"video_queue_full",...}`，经 Cloudflare(FRA 边缘) 返回。**此刻(22:01 GMT+8)上游视频队列仍满**。
- 结论：请求能到达、能鉴权、拿到业务级「队列满」，是上游(agnes)视频子系统晚高峰容量不足，不在我们掌控。

### 我们这侧的健壮性问题（已修，用户授权「只要是 bug 就可以修」）
- 视频提交 `_submit_video_only`(`agnes_provider.py`) 原 `_post_with_retry(max_attempts=2)` 只重试 1 次(4s)就放弃 → 上游说「retry later」却立即 FAILED+退款。
  - 修复：给 `_post_with_retry`/`_apost_with_retry` 加 `backoff_cap:int=20` 参数（替换硬编码 20）；视频提交改 `max_attempts=5, backoff_base=15, backoff_cap=60`（总等待≈165s），桥接数分钟级瞬时饱和。
- 前端 `PeaNode.tsx parseGenError` 在通用 5xx 分支**前**加 `video_queue_full` 专属分支 → 显示「视频生成队列繁忙，上游视频服务暂时满负荷，已自动重试；若持续请稍后再试」，不再误显示「已自动退款」。

## 视频生成参考图失效修复（完成）

### 问题
用户上传参考图/用 AI 生成图做视频参考，生成的视频与参考图完全无关。UI 显示参考图正常、prompt 正确，但 Agnes 返回结果仿佛从未见过该图。

### 根因（两个独立 Bug 叠加）
1. **前端 scheme 校验缺失**：`NodeChatPrompt.tsx:97` 的 `resolveUpstreamMediaUrl` 对 AI 生成图的相对路径 `/media/...` 和 blob: URL 无过滤，直接送入 `reference_images` → 编排器 `_normalize_refs` 静默丢弃（line 178 `else: dropped+=1`）。同文件孪生函数 `NodePromptInput.tsx:65` 和 line 486 的 `getParsed().referenceImages` 收集也有相同缺陷。
2. **编排器 data URI 不兼容视频接口**：上传图的签名 URL 为 `http://localhost:9000/...`，被 `_resolve_internal_ref_via_minio` 下载后转成 base64 data URI 塞给视频 `payload["image"]` 字段。Agnes 视频 API 的 image 只接受 http(s) URL（图片接口 `extra_body.image[]` 数组可以接受 data URI）→ 忽略 → 视频无关。

### 修复
- **前端**：`NodeChatPrompt.tsx:97` + `NodePromptInput.tsx:65` + `NodePromptInput.tsx:486` 增加 `startsWith('http')` 校验，非 http(s) 强制走 `fileKey → getPresignedUrl` 获取真实签名 URL。
- **编排器**：`agnes_provider.py` 新增 `_ensure_http_refs_for_video()` 函数，检测到 data URI 时解码并通过 `storage.store_bytes()` 上传到公开 `gen/` 前缀返回 CDN URL；含 localhost 检测告警（生产需配公网 `PEA_CDN_BASE_URL`）。

### 修改文件
