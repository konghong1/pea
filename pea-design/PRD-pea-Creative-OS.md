## 0. 文档说明与来源

本 PRD 的事实来源是一个**高保真交互原型** `pea-canvas-v12.html`（单文件 HTML/CSS/JS，3308 行）。原型已实现了完整的 UI 结构与交互行为，但**所有"生成/请求"动作目前均为演示（toast / alert）**，未接真实后端。

**重要边界（请开发/决策层注意）：**
- 本 PRD 是"从原型反推需求"，代表**产品意图与设计基线**，不等于经过验证的用户需求。
- 涉及用户动机、付费意愿、市场规模的部分，需补充真实用户研究（访谈 / 问卷 / 数据）后方可固化优先级。
- 原型中所有 AI 生成（图像/视频/音频/3D/Agent）均为前端模拟，**真实能力依赖后端多模型编排服务**，本文档将其列为"集成层需求"，具体模型 SLA 由后端团队确认。

## 1. 产品概述

### 1.1 产品定位
**pea Creative OS** 是一个面向创作者 / 电商运营 / 团队的 **AI 原生创意操作系统**：用户用"一句话 + 画布节点编排"的方式，从创意、脚本、分镜到图像 / 视频 / 音频 / 3D 成片，完成端到端创作，并可直接生成电商套图、发布到社区（TapTV）。

### 1.2 解决的核心问题
| 用户痛点 | 当前方式 | pea 的解法 |
|---|---|---|
| 创作工具碎片化（ChatGPT 写脚本、MJ 出图、剪映剪辑、各平台分发的多窗口切换） | 多工具来回复制粘贴、上下文丢失 | 统一画布 + Agent 编排，创作链路在一处闭环 |
| 电商套图需要设计/摄影/后期多人协作，周期长、成本高 | 外包或自建设计团队，单套图数天 | 上传产品图→AI 智能策划→一键生成主图/详情页整套 |
| 创作过程不可见、难以复用与学习 | 只看到成片 | TapTV 展示"从想法到成片"的逐步过程，可复刻 |

### 1.3 目标用户
- **核心**：个人创作者 / 短视频团队 / 独立设计师（用画布做 AI 短片、IP 宇宙）
- **重要**：跨境电商 / 国内电商运营（用电商套图做主图详情页）
- **延伸**：企业内容团队（共享项目、创作记忆）

### 1.4 核心设计原则（来自原型设计 Token）
- 暗色为主的操作系统质感（`--bg-deep:#0a0a0a`），强调色 `#1fa2dc`（青蓝）。
- 画布是"创作的画布"，而非表单 —— 自由画布、节点连线、所见即所得。
- AI 是"副驾驶"：右侧对话面板 + 技能芯片 + `@` 引用画布内容 + `/` 调用技能。
- 全局统一导航：主页 / 工作空间（画布）/ 电商套图 / TapTV / 竞技场（规划中）。

## 2. 目标与成功指标

> 指标必须可观测、可归因、有基线与目标值。以下基线以原型默认态为参照，真实基线需上线后 2 周校准。

**北极星指标**：周活跃创作者完成的"有效创作产出数"（定义为：单画布 ≥3 节点且触发过 1 次生成 / 或电商套图成功生成 ≥1 套）。

**驱动指标**：
| 指标 | 定义 | 基线（假设） | 目标（90 天） |
|---|---|---|---|
| 画布新建率 | 新用户 7 日内新建画布占比 | — | ≥ 40% |
| Agent 对话激活率 | 进入画布后发送 ≥1 条 Agent 消息 | — | ≥ 55% |
| 电商套图生成转化率 | 完成配置并点击生成 | — | ≥ 30% |
| TapTV 发布率 | 创作产出发布到社区占比 | — | ≥ 15% |

**健康指标**：
- 生成任务成功率（非演示）≥ 95%
- P95 画布首屏渲染 ≤ 1.2s（≤ 50 节点）
- 积分消耗异常率（单用户单日 > 预算 3 倍）告警

## 4. 范围（Scope）

### 4.1 In-Scope（本版 PRD 覆盖）
- M1 画布编辑器全部交互（节点、连线、缩放平移、小地图、检查器、Agent、侧边面板、节点库、右键菜单、快捷键）。
- M2 电商套图全部配置与生成流程（含 AI 策划台、出图规划、属性设置弹窗、结果/案例展示）。
- M3/M4/M5 的功能需求与验收标准（含数据结构）。
- 全局：顶部导航、用户菜单、账户抽屉、积分体系、订阅 Promotion 弹窗、Toast。

### 4.2 Non-Goals（本版明确不做 / 延后）
- **真实 AI 生成能力**：本版 PRD 只定义交互与集成契约，模型推理、排队、回调由生成服务平台负责（见 §11）。
- **竞技场（Arena）**：导航占位，点击提示"即将开放"，不在本版实现。
- **多人实时协作（协同光标 / 实时同步）**：本版仅做单人画布；协作列入 Later。
- **付费收银台**：订阅/充值仅做入口与状态展示，真实支付接入单列 Epic。
- **移动端原生 App**：本版面向桌面 Web（原型 `viewport=1440`），响应式适配仅保证可用，不优化移动体验。
- **社区 UGC 审核后台、创作者结算**：不在本版。

## 5. 全局系统（G）

### 5.1 顶部导航（Top Nav）
- 固定顶栏高度 52px，毛玻璃 `backdrop-filter`，底部 1px 边框。
- 左侧：Logo（pea）+ 当前画布标题区（仅画布页显示：名称 `Creative Concept (0721)` + 元信息 `上次修改于 5 分钟前`，由后端 lastModified 驱动）。
- 中间：导航项 `主页 / 工作空间 / 电商套图 / TapTV / 竞技场`。激活态高亮（accent 色），切换即切换 `.page` 视图（见 `switchPage`）。
- 右侧：`Tapies` 积分显示（默认 200）、社区按钮、分享（复制链接 toast）、通知、头像、编辑、免费体验（打开 Promotion 弹窗）。
- **FR-G1**：导航切换需保留各页面滚动/编辑状态（SPA 单实例，不重新加载）。

### 5.2 积分体系（Tapies）
- 全局积分余额展示于顶栏与用户菜单。
- 电商套图生成按"出图规划数量 × 单价（原型为 10 积分/张）"预扣；需在生成前展示"消耗 X 积分"。
- **FR-G2**：积分不足时，"立即生成"应禁用并引导充值（原型仅展示，需接余额校验）。
- **FR-G3**：积分变更需有流水记录（账单记录入口，本版仅展示）。

### 5.3 通知 / Toast / 分享
- **FR-G4**：Toast 轻提示，1.8s 自动消失，支持堆叠不重叠（原型为单例，需评估多提示场景）。
- **FR-G5**：分享按钮复制当前画布/项目链接到剪贴板，失败降级提示手动复制。
- **FR-G6**：通知中心（铃铛）点击展示通知列表（原型 toast"暂无新通知"，需接通知服务）。

### 5.4 AI 模型 / Provider 抽象（全局可配置）
- 账户中心"AI 提供商"页：Provider 列表（OpenAI / Anthropic / Google / 阿里云·通义 / 百度·文心 / 智谱 AI / Stability AI / Midjourney），每个可开关，并指定默认 Provider。
- 配置持久化（原型用 `localStorage: tn_ai_providers`），**真实环境需同步到用户服务端配置**。
- **FR-G7**：关闭某 Provider 后，若该 Provider 是默认项，自动回退到第一个启用项；下拉中禁用项标记"已关闭"。
- 画布节点 Inspector 的"模型"下拉、Agent 模型切换、生成服务调用，均需读取该配置。

## 6. 模块一：画布编辑器（M1，P0，详细规格）

> 这是文件名所指的核心模块，也是产品的"操作系统内核"。以下给到开发级规格。

### 6.1 用户故事
- 作为创作者，我希望在无限画布上以节点方式组织创意（文本/图像/视频…），以便直观看到创作链路。
- 作为创作者，我希望双击空白处快速添加节点、拖端口连线，以便低摩擦搭建工作流。
- 作为创作者，我希望在右侧用自然语言让 Agent 自动生成/连接节点，以便不懂工具也能创作。
- 作为创作者，我希望点击节点在右侧看到并修改属性（模型/尺寸/提示词），以便精确控制生成。

### 6.2 功能需求（FR）

#### 6.2.1 节点系统（Node）
节点类型定义（取自原型 `NODE_DEFS`）：

| type | 名称 | 类别 | 是否生成型 |
|---|---|---|---|
| text | 文本提示词 | 输入 | 否 |
| ref | 参考图像 | 输入 | 否 |
| image | 图像生成 | 生成 | 是 |
| video | 视频生成 | 生成 | 是 |
| audio | 音频生成 | 生成 | 是 |
| world3d | 3D 世界 | 生成 | 是 |
| story | 分镜脚本 | 结构 | 否 |
| camera | 相机控制 | 结构 | 否 |
| light | 影棚灯光 | 结构 | 否 |
| agent | pea Agent | 智能 | 是 |
| playlist | Playlist 片段 | 智能 | 否 |
| replace | 对象替换 | 智能 | 是 |

- **FR-M1-01**：节点渲染为绝对定位 DOM（`.rf-node`），含：删除按钮、四向连接端口（left/right/top/bottom）、图标、标题、正文、标签 footer。
- **FR-M1-02**：节点支持选中（单击 / `Ctrl+A` 全选 / 框选——原型仅全选，框选列入增强）。选中态描边高亮。
- **FR-M1-03**：双击节点标题进入编辑（contentEditable），回车/失焦提交重命名（原型 `onblur` + Enter）。
- **FR-M1-04**：选中节点后右侧 Inspector 展示该类型属性（见 6.2.6）。
- **FR-M1-05**：生成型节点（image/video/audio/agent/world3d/replace）在 Inspector 提供"⚡ 生成"按钮，触发后端生成任务（本版接集成层）。

#### 6.2.2 画布交互（Canvas Viewport）
- **FR-M1-10**：画布支持平移（拖拽空白处）、缩放（滚轮以光标为中心 `zoomAt`、缩放滑块 25%–200%、`+/−` 按钮、适配视图 `fitView`）。
- **FR-M1-11**：缩放/平移通过 `transform: translate(pan) scale(zoom)` 应用（`applyTransform`）。
- **FR-M1-12**：网格视图开关（`toggleGrid`），小地图（minimap）实时反映节点与视口框（`updateMinimap`）。
- **FR-M1-13**：空画布显示引导提示（双击添加 / 点 ➕ / 查看模板）。
- **性能约束**：≤ 50 节点时交互 ≥ 60fps；连线与重绘为 O(n)，禁止每次全量重建 DOM（原型 `renderNodes` 会移除重建，需优化为差异更新或虚拟列表——见 §12）。

#### 6.2.3 连线（Edges / Connections）
- **FR-M1-20**：从节点端口拖拽到另一节点端口建立连线，记录 `{from, fromPort, to, toPort, color}`。
- **FR-M1-21**：连线用 SVG 贝塞尔曲线绘制（`drawConnections`），随节点移动/缩放实时更新。
- **FR-M1-22**：点击连线可删除（原型 `deleteEdge`）；节点删除时级联删除其相关连线。
- **FR-M1-23**：复制节点（右键"添加并连接" `addConnected`）自动从源节点右侧端口连出新节点。

#### 6.2.4 添加节点入口
- **FR-M1-30**：左侧工具栏 ➕ 打开添加浮层（分类：输入/生成/结构/智能），支持搜索输入（随机/指定类型添加）。
- **FR-M1-31**：双击画布空白 → 在光标处打开添加浮层（`openAddPopover`）。
- **FR-M1-32**：右键画布空白 → 画布菜单（文本/图像/视频/Agent/适配视图）。
- **FR-M1-33**：节点库抽屉（⊞）按分类列出全部节点类型，点击即添加（`buildLib` / `LIB_CATS`）。
- **FR-M1-34**：新节点默认置于视口中心（无坐标时），并自动选中。

#### 6.2.5 文本节点富文本工具条（Text Node Toolbar）
- 选中文本节点显示浮动工具条：颜色、H1/H2/H3/段落、加粗/斜体/列表/对齐/分割线/表情/图片/链接/展开（`textNodeToolbar`）。
- **FR-M1-35**：工具条为画布内联编辑，编辑结果写回节点 body（富文本需定义存储格式，建议 HTML/Markdown）。

#### 6.2.6 右侧 Inspector（属性检查器）
- 双 Tab：`属性` / `对话`。
- **FR-M1-40**：未选中节点 → 展示空态骨架屏 + 操作提示。
- **FR-M1-41**：选中单节点 → 标题输入、描述/提示词文本域、生成型展示模型下拉（按类型映射：image→MJ V8.1/Flux Pro/GPT Image；video→Kling 3.0/Veo 3/Sora/Luma；audio→pea TTS/ElevenLabs；agent→Kimi 2.6/GPT-4o/Claude Sonnet；world3d→pea 3D）。
- **FR-M1-42**：image 节点额外宽/高（默认 1024）；video 节点时长(s)/分辨率（默认 5s/1080p）。
- **FR-M1-43**：多选中 → 展示"已选 N 个节点 + 删除所选"批量操作。

#### 6.2.7 AI Agent 对话面板（右侧"对话" Tab + 工作区入口）
- **FR-M1-50**：输入框支持 Enter 发送；技能芯片 `@扩写脚本 / @生成分镜 / @电影级镜头`（`insertSkill`）；`@` 引用画布内容（`insertAt`）；`/` 调用技能（原型为提示，需实现命令面板）。
- **FR-M1-51**：模型切换下拉（Kimi 2.6 / GPT-4o / Claude Sonnet / Midjourney V8.1 / Kling 3.0 / Seedance 2.0），切换影响 Agent 调用后端。
- **FR-M1-52**：发送后展示"输入中"打字动画（原型 900ms 模拟），Agent 回复按关键词规则（`agentReply`：含"分镜"→加节点并提示；含"视频"→Kling；含"图"→MJ；默认→加节点）。**真实实现需接 LLM + 节点操作 API，规则引擎为兜底**。
- **FR-M1-53**：对话历史 `chatLog` 需跨面板持久（工作区发送也会推入同一 chatLog），刷新不丢失（接后端会话存储）。

#### 6.2.8 侧边面板（Side Panels）
- **FR-M1-60**：搜索面板（🔍）：搜索节点/资源/创作，输入即时过滤（`searchFilter`）。
- **FR-M1-61**：评论面板（💬）：评论列表 + 输入框（Enter 发送，原型 toast）。
- **FR-M1-62**：历史记录面板（🕐）：展示操作时间线（添加节点/调整参数/生成/连线/创建），需接操作日志服务。
- **FR-M1-63**：文件面板（📁）：当前项目资源列表（图/视频/音频/脚本）。
- 面板互斥打开，点击遮罩/外部关闭（`closeSidePanels`）。

#### 6.2.9 右键菜单与快捷键
- **FR-M1-70**：节点右键 → 复制节点 / 添加并连接 / 删除节点（`showContextMenu`）。
- **FR-M1-71**：快捷键：`Delete/Backspace` 删选中、`Esc` 关闭弹层+清选、`Ctrl/Cmd+A` 全选、`滚轮`缩放、`拖空白`平移（原型 `keydown` / `wheel` 监听）。

### 6.3 数据模型（M1）

```ts
type NodeType = 'text'|'ref'|'image'|'video'|'audio'|'world3d'
  |'story'|'camera'|'light'|'agent'|'playlist'|'replace';

interface CanvasNode {
  id: string;            // node{seq}
  type: NodeType;
  x: number; y: number;  // 画布坐标
  title?: string;        // 可重命名
  body?: string;         // 提示词/描述（富文本）
  // 生成型参数
  model?: string;
  params?: Record<string, any>; // width/height/duration/resolution...
}

interface Edge {
  id: string;
  from: string; fromPort: 'left'|'right'|'top'|'bottom';
  to: string;   toPort: 'left'|'right'|'top'|'bottom';
  color?: string;
}

interface Canvas {
  id: string;
  name: string;          // "Creative Concept (0721)"
  ownerId: string;
  nodes: CanvasNode[];
  edges: Edge[];
  zoom: number; pan: {x:number;y:number};
  lastModified: number;  // 驱动顶栏"上次修改于 X 分钟前"
}
```

### 6.4 UI 状态与边界
- 空画布、单选中、多选中、连线中、生成中、加载失败 —— 均需明确视觉态。
- 节点超上限（建议 ≤ 200）需提示性能预警。
- 连线端口命中需有容差（建议 12px），移动端/触控暂不支持连线。

### 6.5 验收标准（M1，节选）
| 编号 | 验收标准 |
|---|---|
| AC-M1-01 | 双击空白在光标处弹出添加浮层，选择类型后节点出现在该坐标并自动选中 |
| AC-M1-02 | 拖端口 A→B 建立连线，移动任一节点时连线实时跟随 |

## 7. 模块二：电商套图（M2，P0，详细规格）

### 7.1 用户故事
- 作为电商运营，我希望上传产品多视角图并填写卖点，以便 AI 理解商品。
- 作为运营，我希望 AI 自动策划一套"主图/详情页"出图规划，以便不必懂设计也能拿到完整套图。
- 作为运营，我希望逐项微调（痛点方向/比例/分辨率/参考图），以便贴合品牌。
- 作为运营，我希望一键生成并看到结果，以便直接上架。

### 7.2 功能需求（FR）

#### 7.2.1 上传产品图（Upload）
- **FR-M2-01**：支持本地上传 + 图片库两种来源（Segmented 切换 `tabLocal/tabLib`）。
- **FR-M2-02**：拖拽或点击上传，格式 JPG/PNG/WEBP，单张 ≤ 10MB；缩略图可单张删除。
- **FR-M2-03**：展示警告横幅：要求"同一款产品不同角度/细节图，勿混传不同类"，可关闭。
- **FR-M2-04**：强烈建议多视角（≥3 张）以提升还原度（使用说明第 1 条）。

#### 7.2.2 核心卖点（USP）
- **FR-M2-05**：文本域（maxlength 500，实时字数统计），提示填写名称/卖点/人群/场景/参数。
- **FR-M2-06**："✨ AI 帮写"按钮，基于已填信息调用 LLM 补全（原型 alert 演示）。

#### 7.2.3 市场配置（Market，可折叠）
- **FR-M2-07**：电商平台（亚马逊/淘宝天猫/京东/抖音电商/拼多多/小红书）、目标市场（北美/欧洲/东南亚/拉美/中东/日韩/全球）、文案语种（英/中/日/德/法/西/葡/阿）、视觉风格（高级质感/清新自然/科技未来/复古怀旧/简约极简/活泼可爱）。
- **FR-M2-08**："🌍 AI 推荐" —— 根据类目/卖点推荐市场配置（原型 alert）。

#### 7.2.4 全局输出配置（Output，可折叠）
- **FR-M2-09**：模型（Banana-pro/Banana-lite/Gpt-image-2/通用）、分辨率（1K/2K/4K）、每类型出图数（stepper ≥1）、图片比例（自适应/3:4/16:9/1:1/4:3）。

#### 7.2.5 出图规划列表（Plan List，核心）
- **FR-M2-10**：规划类型（PLAN_TYPES，最多 50 个）：产品白底图、亚马逊主图、细节特写、产品多角度、首屏视觉图、核心卖点图、客户痛点展示、场景图(非服饰)、试穿试戴场景、产品代言互动、活动海报(极速)。
- **FR-M2-11**：`AI 智能策划台` 打开居中弹窗，三 Tab：推荐类型 / 自定义子任务 / 已保存模板；勾选类型（计数上限 50），确认后写入规划行。
- **FR-M2-12**：规划以"编号行"展示（`plan-row`）：序号、名称、极速标签、参数（数量/比例/分辨率）、复制/删除/设置›。
- **FR-M2-13**：每行"设置›"打开属性设置弹窗（见 7.2.7）；"清空"清空全部。
- **FR-M2-14**：积分预估 = 规划行数 × 10，实时更新（`updateTotalPoints`）。

#### 7.2.6 生成与结果
- **FR-M2-15**：底部固定"✦ 立即生成（消耗 N 积分）"，点击收集配置并触发生成任务（原型 alert 展示收集内容）。
- **FR-M2-16**：结果区（AI 创作结果 Tab）默认展示"热门套图示例"画廊，按类目筛选（服装鞋帽/3C数码/箱包配饰/个护美妆/日用百货/其他）；空状态提示"尚无作品"。
- **FR-M2-17**：创作案例 Tab 复用画廊数据；"创作记录"入口（规划中）。
- **FR-M2-18**：画廊卡片支持"查看详情 / 生成同款"（生成同款带入对应配置）。

#### 7.2.7 单条属性设置弹窗（Item Settings）
- 左栏：个性化设置（按类型动态字段，如 pain：痛点方向/呈现结构/对比方式/解决路径/共鸣场景；bg：背景色/光影方向）+ 通用设置（文案语种/目标市场/电商平台/规格风格/文案需求/色调倾向），均支持"AI帮填(免费)"。
- 右栏：补充说明（textarea maxlength 2000 + 计数）、出图设置（模式通用/Banana-pro/Gpt-image-2、分辨率 1K/2K/4K、数量、比例）、参考图片（最多 4 张）。
- **FR-M2-19**：设置存于 `itemSettings[typeId]`，影响该条生成参数。

### 7.3 数据模型（M2）
```ts
interface ProductImage { id; url; angleTag?; createdAt; }
interface PlanItem {
  typeId: string;            // 见 PLAN_TYPES
  count: number; ratio: string; resolution: '1K'|'2K'|'4K';
  personal?: Record<string,string>; // 个性化字段
  general?: Record<string,string>;  // 通用设置
  supplement?: string;
  refs?: string[];           // 参考图 url，≤4
}
interface EcomProject {
  id; ownerId;
  images: ProductImage[];
  usp: string;
  market: {platform; region; lang; style};
  output: {model; resolution; perTypeCount; ratio};
  plan: PlanItem[];          // 出图规划
  estimatedPoints: number;  // = plan.length * 10
}
interface GenerationJob {
  id; projectId; planItemIds; status: 'queued'|'running'|'done'|'failed';
  outputs: {url; typeId}[]; pointsSpent; createdAt;
}
```

## 11. 跨模块数据模型与接口约定（建议）

> 以下为**集成契约建议**，供后端团队对齐，不在本版实现细节内固化。

1. **用户服务** `/user`：profile、settings（含 AI provider 配置）、points balance、subscription。
2. **画布服务** `/canvas`：CRUD、节点/连线存储、操作日志（历史记录）、自动保存（debounce）。
3. **生成服务** `/generate`：接收 `{type, model, params, refs}`，返回 jobId；异步回调/轮询状态与结果 URL。需支持多模型路由（按 §5.4 provider 配置）。
4. **电商套图服务** `/ecom`：project、plan、generation job（批量编排多 planItem）。
5. **社区服务** `/community`：feed、detail（含步骤）、发布（将画布产出发布为 TapTV 条目）。
6. **鉴权**：所有接口需用户 token；积分校验在生成前由服务端预扣。

**数据一致性**：画布/项目需自动保存（原型为内存态，刷新丢失——**P0 必须解决**）。

## 12. 非功能性需求（NFR）

| 维度 | 要求 |
|---|---|
| 性能 | 画布 ≤50 节点 ≥60fps；首屏 ≤1.2s(P95)；生成任务创建 <2s 响应 |
| 持久化 | 画布/项目自动保存（防丢失）；账户配置服务端同步 |
| 兼容性 | 桌面 Chrome/Edge/Safari 最新 2 版；不承诺移动原生体验 |
| 安全合规 | 用户数据默认符合个人信息保护法/GDPR；上传图须知会用途；参考图不跨用户泄露；积分/订阅涉及支付需 PCI 意识 |
| 可观测 | 生成成功率、积分消耗、画布操作埋点；异常告警 |
| 可访问性 | 基础键盘可达（已实现快捷键）；对比度达标；暂不做读屏深度优化 |
| 技术债注意 | 原型 `renderNodes` 全量重建 DOM 在节点多时会有性能问题，正式实现需差异更新 |
