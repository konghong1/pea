设计要点
  • 一体化: 单个胶囊容器, 中间一道能量桥连接「消耗」与「发射」, 视觉上是一体而非两个按钮
  • 3D 悬浮: 多层 box-shadow(顶部高光 + 底部暗面 + 远场辉光) + 缓慢上下浮动动画
  • 真实钻石: 经典宝石切面(冠面/腰面/亭面/底尖), 多层渐变 + 棱线高光 + 旋转动画
  • 火箭发射舱: 替代单薄的箭头, 增强「生成 / 触发算力」语义, hover 时向上推进
  • 能量桥: 中间流光颗粒, 暗示「能量从消耗流向发射」
  • 三态: default / disabled / submitting(可观察色温/动画/光晕差异)
  • 无障碍: prefers-reduced-motion 自动关闭所有动画
  • 性能: 仅用 transform/opacity/box-shadow 动画, 60fps, 走 GPU 合成层
